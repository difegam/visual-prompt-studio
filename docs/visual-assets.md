The homepage illustrations are referenced from `src/content/homepage/-index.md`; sample article covers are set in each post's frontmatter. Keep informative image alt text at the content source. The homepage feature images are decorative because their adjacent headings and copy already express their subject.

Replace or remove these generic examples when adapting the starter to a real site. The visual set contains no brand mark, author portrait, testimonial, or claim about a real product.
