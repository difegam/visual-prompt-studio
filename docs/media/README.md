# README media to capture

The README references these files. Capture them from `pnpm dev` at a 1440 px wide desktop window, keep GIFs under 8 MB, and use the light theme.

| File              | What to show                                                                                 |
| ----------------- | -------------------------------------------------------------------------------------------- |
| `demo.gif`        | About 30 s: pick Poster and a goal, apply a 2026 starter, change one layer, copy the prompt. |
| `directions.png`  | Recommended directions plus the explorer with a few filter pills active.                     |
| `layers.gif`      | Switch the Layout, Imagery and Finish tabs; the proof sheet updates.                         |
| `font-picker.png` | The font picker dialog with a live specimen.                                                 |
| `targets.gif`     | Change the target and show the compiled prompt changing.                                     |
