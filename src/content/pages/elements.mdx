### Paragraph and emphasis

Markdown keeps editorial text close to its structure. Use headings in order and write link text that explains its destination.

This paragraph includes **strong text**, _emphasis_, and an [example link](https://example.com).

### Lists

1. Use ordered lists when sequence matters.
2. Keep each item focused on one action.
3. Use unordered lists for groups without an order.

- Content collections validate editorial fields.

### Accordion

<Accordion client:load title="When should I use MDX?">

Use MDX when prose needs an embedded component. Prefer ordinary Markdown for content that does not need interactive UI.

</Accordion>

<Accordion client:load title="How do I add an image?">

Use media you have permission to publish. Add useful alt text when an image conveys information; use empty alt text for decorative images.

</Accordion>

### Video shortcodes

Remote video embeds can contact third-party services and may need consent or a privacy review. Add a real video only after checking its source, privacy behavior, and accessibility.

